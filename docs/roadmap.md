# Roadmap

## Phase 0 — Foundation ✅
- Tauri + React + Tailwind scaffold
- SQLite database
- Base layout and routing

## Phase 1 — MVP ✅
- CV builder with section forms
- 6 CV templates with live preview
- Save/load/delete CV versions
- PDF export

## Phase 2 — Tracker & Match ✅
- Application tracker CRUD
- Job description paste and match scoring

## Phase 3 — Local AI ✅
- Ollama integration for tailored CVs and cover letters
- Rule-based fallback when Ollama unavailable

## Phase 4 — Job Scraper ✅
- RemoteOK scraper
- Rank and save-to-tracker flow

## Phase 5 — Career Tools ✅
- Skill gap analyzer
- Interview coach
- LinkedIn optimizer
- Salary insights

## Phase 6 — Polish ✅
- Drag-and-drop section ordering
- 6 CV templates (modern, ATS, minimalist, creative, executive, one-page)
- Portfolio HTML generator
- Windows installer via `npm run tauri build`

## Future
- DOCX/Markdown export
- Additional job scrapers
- Plugin marketplace for community templates
